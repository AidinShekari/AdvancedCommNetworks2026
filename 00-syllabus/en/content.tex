\CNsection{}{Course Objectives}

By the end of this course, students will be able to:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Trace the complete evolution of mobile networks from GSM (2G) through UMTS (3G), LTE (4G), 5G NR/\allowbreak{}SA, to emerging 6G concepts.
\item
  Explain WHY each generation was developed, WHAT problem it solved, and HOW traffic flows through each architecture.
\item
  Analyze core network architectures: circuit-switched, packet-switched, all-IP EPC, and service-based 5G Core.
\item
  Describe mobility management, handover mechanisms, and their evolution across generations.
\item
  Understand network slicing, QoS frameworks, SDN, and NFV in modern networks.
\item
  Explain 5G Core procedures (registration, authentication, PDU session) at the signaling level.
\item
  Critically assess 6G research directions (ISAC, RIS, AI-native, cell-free MIMO, sub-THz).
\end{enumerate}

\CNsection{}{Project}

Students work individually or in pairs (max 2) on a semester project. Topics may include:

\begin{itemize}
\tightlist
\item
  Comparative analysis of LTE vs 5G for a specific use case
\item
  Network slicing design for an enterprise scenario
\item
  Implementation of a scheduling algorithm (using the wireless\_\allowbreak{}lab simulator)
\item
  6G research topic survey and feasibility analysis
\item
  Signaling analysis using real-world packet captures
\end{itemize}

\textbf{Deliverables:} Proposal (Week 13), Final Report + Demo/\allowbreak{}Presentation (Week 16)

\CNsection{}{Academic Integrity}

All submitted work must be original. Collaboration on labs is encouraged for discussion but each student submits individually. Plagiarism will result in a zero for the assignment and referral to the academic integrity board.
