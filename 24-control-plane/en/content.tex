\CNsection{1}{Control Plane Concept}

The \textbf{Control Plane} (C-Plane) handles all \textbf{signaling} in the mobile network — the messages that set up, manage, modify, and tear down connections. It does NOT carry user data.

\textbf{Control Plane responsibilities:}

\begin{itemize}
\tightlist
\item
  \textbf{Authentication \& Security}: Verify subscriber identity, establish encryption
\item
  \textbf{Registration \& Mobility}: Attach, detach, tracking area updates, handovers
\item
  \textbf{Session Management}: Establish/\allowbreak{}modify/\allowbreak{}release PDU sessions or bearers
\item
  \textbf{QoS Negotiation}: Agree on quality parameters for data flows
\item
  \textbf{Paging}: Locate idle UEs for incoming data/\allowbreak{}calls
\item
  \textbf{Policy \& Charging}: Apply operator rules to sessions
\end{itemize}

\textbf{Key principle:} The control plane ``programs'' the user plane — it sets up the tunnels, rules, and routing that the user plane then uses to forward data.

\CNboxsection{Key Takeaways}

\begin{CNbox}[unbreakable]{sum}{Key Takeaways}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Control plane = signaling brain}: Sets up tunnels, authenticates users, manages mobility
\item
  \textbf{NAS is end-to-end (UE\ensuremath{\leftrightarrow}Core)} — transparent to RAN; separate security context
\item
  \textbf{RRC manages the radio} — connection setup, measurements, handover commands
\item
  \textbf{5G adds RRC\_\allowbreak{}INACTIVE} state for fast resume and IoT efficiency
\item
  \textbf{NGAP replaced S1AP} — supports slicing, QoS flows, and three RRC states
\item
  \textbf{GTP-C evolved}: v1 (3G) \ensuremath{\to} v2 (4G) \ensuremath{\to} replaced by PFCP+HTTP/\allowbreak{}2 in 5G
\item
  \textbf{HTTP/\allowbreak{}2 SBI is revolutionary} — cloud-native, RESTful, auto-scalable NF communication
\item
  \textbf{Signaling evolution}: SS7 (binary, TDM) \ensuremath{\to} Diameter (binary, IP) \ensuremath{\to} HTTP/\allowbreak{}2 (JSON, cloud-native)
\end{enumerate}

\end{CNbox}
